🧪 Testar

Os botões da prévia tocam só aqui. Os de Testar no OBS mandam o alerta pros alertas abertos (no overlay da StreamElements) e pedem a senha do Salvar na live.

Na prévia
Testar no OBS

prévia · use os botões de teste
Colocar na StreamElements (uma vez só)
  1. Na StreamElements: Overlays → abra o overlay que já está no OBS → + → Static / Custom → Custom widget
  2. No widget: Settings → Open editor. Cole cada código abaixo na aba de mesmo nome (HTML, CSS e JS) e clique em Done
  3. Deixe o widget do tamanho do overlay (1920 × 1080, posição 0, 0) e salve o overlay
  4. Se o overlay já tem o AlertBox da StreamElements, desligue nele os tipos que estes alertas fazem, pra não tocar dois
  5. Teste com o Emulate da StreamElements ou com os botões daqui
